# Обзор

OpenE2E - это ручной безопасный мессенджер для обмена зашифрованными сообщениями через любой канал: от SMS и email до мессенджеров, соцсетей и других недоверенных каналов.

Приложение локально шифрует и расшифровывает сообщения, а между людьми передаётся уже зашифрованный текст любым доступным способом. Это делает проект полезным там, где нет удобного безопасного канала связи.

OpenE2E использует **Matrix OLM** через библиотеку `voldozemac`, **AES-256-GCM** для шифрования сообщений и **сквозное шифровние с совершенной прямой секретностью (PFS)**.

Подробнее о модели шифрования и внутреннем устройстве: [OLM.ru.md](OLM.ru.md)

# Для чего это?

**OpenE2E** позволяет отправлять сообщения через *любой* канал (текст, электронную почту, социальные сети и так далее) так, чтобы только вы и получатель могли их прочитать. Вы шифруете сообщения на своем устройстве, копируете зашифрованный текст и вставляете его где угодно.

## Почему конфиденциальность важна

**Сбор и анализ данных.** Компании и государственные органы собирают информацию о вашем местоположении, контактах, истории просмотров и поведении онлайн. Эти данные используются для создания профилей, предсказания предпочтений и целевого воздействия. В некоторых случаях они также используются для выявления и отслеживания "проблематичных" групп населения.

**Автоматизированный анализ контента.** С развитием систем машинного обучения появились инструменты, способные автоматически анализировать, категоризировать и фильтровать огромные объемы коммуникаций. Ваши сообщения могут быть просканированы на предмет определенного контента, отмечены алгоритмами или переданы властям. Хотя такие системы пока не совершенны и дают ложные срабатывания, они становятся все более точными и распространенными.

**Что это значит на практике.** Даже если вы не делаете ничего незаконного, ваши частные размышления, планы и мнения могут быть неправильно интерпретированы алгоритмом, извлечены из контекста или использованы против вас позже, например, при устройстве на работу, рассмотрении кредита или в судебном процессе.

**Почему шифрование сквозое шифрование имеет значение:** Когда ваши сообщения зашифрованы, ни компании, ни государственные системы не могут их просканировать или анализировать. Ваша коммуникация остается видна только вам и получателю - вне досягаемости массового мониторинга и алгоритмического анализа.

OpenE2E гарантирует, что ваши приватные сообщения защищены от перехвата, анализа и цензуры со стороны третьих лиц. Ваши данные остаются под вашим контролем.

# Возможности

- **Ручной безопасный чат** - Обмен зашифрованными сообщениями через копирование с вставкой и любой канал
- **Сквозное шифрование** - Сообщения шифруются локально и доступны только адресату
- **Совершенная прямая секретность** - Прошлые сообщения остаются защищёнными даже при компрометации будущих ключей
- **Работа через любой канал** - SMS, email, мессенджеры, гос. платформы и другие публичные каналы
- **Локальное хранение** - Все данные остаются на вашем устройстве
- **Зашифрованное хранение** - Сообщения и сессии хранятся локально в зашифрованной базе данных
- **Chat-like интерфейс** - Удобный UI на **Slint**
- **Написан на Rust** - Безопасно и производительно

# Как это работает

1. **Создайте сессию** - Начните новый диалог в приложении
2. **Обменяйтесь публичными ключами** - Сгенерируйте эфимерный публичный ключ и передайте его контакту любым каналом
3. **Получите ключ собеседника** - Вставьте его публичный ключ в приложение, чтобы установить сессию
4. **Напишите сообщение** - Введите текст в приложении
5. **Зашифруйте и скопируйте** - Приложение шифрует сообщение локально и выдаёт шифр для отправки
6. **Получите шифр** - Вставьте зашифрованное сообщение от собеседника в приложение
7. **Расшифруйте локально** - Приложение расшифровывает сообщение на вашем устройстве и показывает его в удобном виде
8. **Продолжайте диалог** - Повторяйте процесс для дальнейшего общения

# Установка

## Установка из исходного кода

### Сборка из исходника

**Требования:**
- LLVM Clang
- Rust

```bash
git clone https://codeberg.org/bazelik-dev/OpenE2E.git
cd OpenE2E
cargo build --release
./target/release/OpenE2E
```

Добавьте `--features gui` в билд команду для Slint UI.

## Установка из предскомпилированных бинарников

### Установка

- Перейдите на страницу [Releases](https://codeberg.org/bazelik-dev/OpenE2E/releases) и скачайте последний бинарник (CLI или GUI)

### Проверка

- Скачайте файл подписи `.asc` со вкладки releases.
- Проверьте подпись: `gpg --auto-key-locate keyserver --keyserver-options auto-key-retrieve --verify OpenE2E*.asc $(find . -maxdepth 1 -name 'OpenE2E*' ! -name '*.asc')`
- Ключ должен совпадать с ключом опубликованным по адресу: https://keys.openpgp.org/vks/v1/by-fingerprint/C4C5BDC6C5E4C96CF12B3E85B7BBEB3BC5439F72

# Безопасность

- **Совершенная прямая секретность (PFS)** - Алгоритм Double Ratchet в OLM обеспечивает сохранность прошлых сообщений даже при компрометации долгосрочных ключей
- **Сквозное шифрование** - Содержимое сообщений видно только двум конечным точкам
- **Только локальное хранение** - Нет облачной синхронизации и серверного хранения сообщений
- **Ручной обмен ключами** - Без автоматических допущений о доверии
- **Независимость от канала** - Зашифрованные данные можно передавать практически через любой канал

### Защита данных

Сообщения и сессии хранятся локально в fjall DB, все данные сообщений шифруются с помощью AES-256-GCM, а все данные сессий и аккаунтов шифруются с помощью AES-CBC-HMAC. Каждое сообщение использует случайно сгенерированный 12-байтовый nonce для обеспечения уникальности шифротекста.

Все ключи шифрования вычисляются из пароля пользователя и хранятся в памяти во время сеанса. Ключи никогда не записываются на диск и не сохраняются после выхода из системы.

- Требуется ручной обмен ключами
